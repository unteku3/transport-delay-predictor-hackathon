# Команды итогового решения

Все команды запускаются из корня.

| Задача | Скрипт |
|---|---|
| Стек без Docker | `run_dispatch_local.py` |
| Проверка REST, WebSocket и обрыва | `smoke_dispatch.py` |
| Повторить итоговый CSV без обучения | `generate_submission.py` |
| Экспорт причинной очистки | `clean_csv.py` |
| Пересобрать интерфейс | `build_dashboard.py` |
| Обновить API-схемы | `export_openapi.py` |
| Обновить PyDoc | `build_code_docs.py` |

Скрипты обучения, подбора и исследовательских аудитов не включены в публичную поставку.
