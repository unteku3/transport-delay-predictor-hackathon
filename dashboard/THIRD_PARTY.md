# Frontend provenance

Layout and `support.js`: user-supplied Claude Design export, `PredictorApp v3.dc.html`.
The original export in Downloads was not modified. The runtime's three CDN URLs
were replaced with local vendor paths; original SRI digests were verified.

Vendored dependencies (licenses included next to each asset):

| React | 18.3.1 | `https://unpkg.com/react@18.3.1/umd/react.production.min.js` | MIT |
| ReactDOM | 18.3.1 | `https://unpkg.com/react-dom@18.3.1/umd/react-dom.production.min.js` | MIT |
| Babel standalone | 7.29.0 | `https://unpkg.com/@babel/standalone@7.29.0/babel.min.js` | MIT |
| OpenLayers | 10.10.0 | `https://cdn.jsdelivr.net/npm/ol@10.10.0/dist/ol.js` | BSD-2-Clause |
