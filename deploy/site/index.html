Predictor Dispatch

Демонстрация прогнозирования задержек транспорта по историческому NDTP-потоку.

Открыть дашборд · Swagger API · Метрики · Документация по коду

Сценарий проверки

  1. Откройте дашборд. Поток уже запущен: CSV преобразуется в NDTP TCP и проходит очистку.
  2. Выберите ТС или план на карте. Сравните текущее отклонение и прогноз целевого события.
  3. Откройте карточку алерта: прогноз выдаётся только при горизонте 10–15 минут до планового события.
  4. В метриках проверьте packets_received, protocol_errors, inference_failures, inference_latency_ms и stream.

Модель и время

Live-модель: Optuna CatBoost, 69 признаков. Модель выдаёт задержку в секундах, не вероятность. Время виртуальное, данные исторические; это не городской транспорт сегодня. Начало окна выбрано по временам запросов, без отбора по качеству прогнозов.

После завершения потока начинается новая сессия с очищенным состоянием и метриками. Во время перехода данные кратко недоступны. Отсутствие алертов в начале сессии допустимо.

Ограничения

План одного ТС не является реестром маршрутов. Причина задержки и индивидуальная погрешность могут быть неизвестны. Метрики replay — на development-данных, не независимая online-валидация. Управление остановкой потока доступно только оператору.
