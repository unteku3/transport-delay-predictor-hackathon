# Соответствие заданию хакатона

Основано на задании, предоставленном командой. Срок сдачи: 27 сентября, 23:59 МСК.
Нужны и CSV в Data Science, и последняя версия формы со ссылкой/описанием приложения.

| Требование | Реализация и границы |
|---|---|
| Независимые ML / Backend / Dashboard | `ml/service/`, `backend/`, `dashboard/`; связь HTTP и WebSocket |
| Docker | Четыре контейнера: ML, backend, replay, dashboard |
| NDTP поток | TCP, CRC, handshake, Nav00; исторический replay, не подключение к внешнему городскому потоку |
| Очистка и расписание | Причинная очистка, DataGuard, план ТС, скорость и стоянка по доступным измерениям |
| Горизонт 10–15 минут | Проверяется при выдаче прогноза; поздние ответы вне окна не публикуются |
| Прогноз вероятности | Пока точечная задержка в секундах; калиброванная вероятность отсутствует |
| Ошибка прогноза | MAE по опубликованным допустимым исходам replay; индивидуального интервала ошибки нет |
| Паттерн и причина | Диагностические признаки доступны; доказанная причина задержки не определяется |
| Карта и уровни риска | GPS-треки, планы, цвета по величине задержки; полноценного реестра маршрутов нет |
| Карточки инцидентов | ТС, время события, прогноз и доступные свидетельства; неизвестные поля null |
| Надёжность | TCP reconnect, stale, fallback при отказе ML; состояние в памяти |
| Документация | Swagger/OpenAPI, docstring/PyDoc и описание архитектуры |
| Map matching | Проекция на отрезки плана; дорожного map matching нет |
| What-if | Ограниченные сценарии с явными предположениями; резервное ТС не симулируется как доказанный эффект |
| GPU / ONNX / TensorRT | В текущем runtime не используются |

По заданию PyTorch/GPU и оптимизации — рекомендации/дополнительные возможности.
Система не выдаёт порог задержки за вероятность. ETA следующей остановки не заменяет
прогноз целевого события, если это разные события. Replay на development-данных
не подтверждает переносимость на новые дни и независимую online-точность.
